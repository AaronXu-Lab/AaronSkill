# 画布环境初始化（独立模块）

仅初始化、现有环境缺失能力、环境变更导致能力失效时读取。这个模块负责承载能力，不负责业务分支、字段设计或评论内容。可单独执行并交付；业务设计通过就绪记录消费其结果。

## 检测、复用与增量补齐

检查项目约定、包清单与锁文件、现有画布路由、节点/边注册、预览入口、Fake 开关、布局和验收记录。对下列能力逐项记为“已验证可复用 / 缺失 / 失效 / 本次不适用”，附路径或验证证据。已有记录需核对相关依赖、路由和组件接口是否变化；有效证据可以复用，不重复初始化。

优先顺序：现有画布能力 → 现有依赖与项目基础设施 → 为确定缺口引入最小依赖。比较隔离、动态尺寸、交互控制、路由定制及维护成本；不强制 React、React Flow、iframe 或某个 UI 库。需新增依赖时遵守项目包管理、兼容性和许可约定，按当前官方资料核实所选 API。只修补本次所需缺口，保留现有路由、布局和用户改动。

## 基础能力清单

| 能力 | 实施与通过条件 |
| --- | --- |
| 独立入口 | 画布路由与独立场景预览入口可直达、刷新、返回；遵循项目路由与演示开关，不替换业务入口；非法场景 ID 给出可理解的空态 |
| 节点与边 | 定义稳定节点 ID、预览场景、变更类别、位置；边具有稳定 ID、源/目标及端口、触发条件和标签；同一对节点多条边不可 ID 冲突。注册 UI 节点与语义节点，边描述流程而非默认允许用户改业务关系 |
| 预览隔离 | 每实例独立状态和生命周期；Portal、遮罩、焦点陷阱、Esc、滚动锁局限于预览视口；输入、菜单、按钮校验和关闭重开可用。共享主题与组件，隔离可变 store、定时器和演示持久化命名空间 |
| 视口控制 | 缩放、平移、聚焦、适配全图、重置有可发现入口；区分重置布局、重置视口和重置场景，避免隐式清除输入。内容滚动不变成画布平移，输入快捷键不触发画布操作 |
| 拖拽 | 仅标题命中区可拖，标题中的按钮和链接也排除；内容区域禁止节点拖拽和平移。支持缩放后的正确坐标换算；跨 iframe 用标题上的可靠 pointer capture 或等价机制，处理 pointerup、pointercancel、lost capture、卸载并清理监听器 |
| 聚焦 | 点击节点或预览内部选中当前节点、突出相邻边并淡化无关边；不抢输入焦点，不在输入时反复移动视口；需要移到可见位置时使用独立聚焦动作或首次选择。点击空白恢复全部连线 |
| 连线路由 | 使用实测节点边界、端口与安全间距生成正交避障路径；节点拖动、内容变化、字体加载及尺寸更新后重新计算。未测量尺寸只能暂用估计，测量后必须替换 |
| 标签和降级 | 标签选在足够长的安全线段并检测其矩形与节点、其他标签碰撞；必要时分配走线通道、移位或调整布局。无避障路径时提示并调整间距/端口或显示明确降级状态，不能静默画穿弹窗的线冒充通过 |

## 隔离实现选择

可用独立文档/iframe 获得独立视口，或在现有运行环境使用独立根、受控 Portal 容器与焦点管理。后者必须实际验证焦点陷阱和全局滚动锁不互相干扰，单纯把组件包进 div 不等于隔离。

使用 iframe 时：保证主题与资源正常载入；同源可桥接选择与尺寸事件，跨源使用经过 origin、source、消息类型及场景实例 ID 校验的消息协议，禁止任意代码消息。设置 title，按需求收紧权限；iframe 本身不能保证请求无副作用。拖拽时不永久覆盖预览或禁用其指针事件。重复载入和卸载均清理桥接监听。

## 就绪记录与出口

在目标项目沿用已有文档位置，无约定时采用画布目录旁的环境记录，包含：

- 画布/预览入口，承载实现与依赖选择理由。
- 节点、边、场景适配器、主题和 Fake 入口的路径与接口。
- 上表能力状态、缺口、本次补齐项、验收证据及适用版本/变更范围。
- 重置语义、隔离方案、临时资源清理结果、需重新初始化检查的变更条件。

以两个同时打开且可独立输入和关闭重开的实际组件实例完成冒烟，覆盖跨预览拖动、动态高度连线、视口控制及无副作用。可复用项目已有实例，不为初始化编造业务流程。

必要能力通过则标记 ready 并返回业务流程；只要求初始化时直接交付。失败可在已授权本地范围修复；隔离无法保证、依赖缺失或运行条件不可用时标记 blocked 并报告具体缺口。禁止删除重建整套画布作为默认恢复方式。
