# 验收矩阵与证据

初始化执行基础设施行；新业务执行全部适用场景；局部修改根据共享影响范围选择回归。每项记录场景 ID、操作、期望、观察结果及截图/日志/检查输出位置；不适用说明理由。

| 范围 | 操作与可观察的通过条件 |
| --- | --- |
| 依赖与可复现性 | 记录实际使用的依赖版本，确认清单、锁文件和安装结果一致；本次新增依赖有相应授权且能被导入、通过项目构建。与 canvas-kit 参考版本不同不构成失败 |
| 入口与覆盖 | 直达并刷新 `/<业务路由>/design-canvas` 及每个受影响流程的 `?preview={name}`，旧地址重定向到新路径且 query 原样保留，预览只含该流程且可从入口走到各结果，未知名称显示空态；从各实际调用方核对已用组件；覆盖表无未解释遗漏，提议与不可达旧代码明确分开 |
| 同时交互与隔离 | 至少两个预览并列，分别输入/选择、打开菜单、Tab 与 Esc；A 的状态、Portal、遮罩及关闭不干扰 B，父画布可继续操作 |
| 关闭重开 | 对适用场景用关闭图标、取消、完成等真实出口退出并重开；状态保留/重置符合定义，重复操作不积累监听器或卡死焦点 |
| 拖拽命中区 | 标题可拖，内容输入、选择文字、菜单与按钮不拖节点，标题栏内的控件单击一次即生效；缩放后跨 iframe 边界拖动并释放/取消，节点不跳跃、不粘住，内容仍可操作；拖动几何自检：对每个流程做「每个节点 × 若干方向小幅拖动」，三项全过——点位移不超过拖动距离、无斜线段、原本共点的边拖动后仍共点（参考实现 `checkDragGeometry`）；再挑一个扇出节点、一个多入边节点真实拖动复测，扇出主干、合并末段、端口进入方向与标签位置都保持 |
| 视口与聚焦 | 右下角控件组的放大、缩小、适配全图（Shift+1）、缩放到选中卡片（Shift+2）与重置布局按定义工作，不可用时置灰；目录收起、展开后画布重新适配；节点内点击淡化无关边而保留输入焦点，空白恢复；内容滚动不带动画布 |
| 动态连线 | 初次测量、拖动、内容增高及窄/宽视口后逐流程满足 [连线指标](initialization.md#连线指标)：主路径零交叉、边不穿节点、标签零重叠、每边至多 2 个拐点、无回指边；有去向的返回、取消以底栏出口呈现，悬停显示的去向正确，原地操作不列；跨流程无连线 |
| 视觉呈现 | 不看代码，用默认打开后的截图并与 [canvas-kit](../assets/canvas-kit/) 的 HTML 标准件并排对照，按 [画布呈现规范](canvas-presentation.md) 逐条判断：首屏看到完整流程、主路径在同一基线直线推进、扇出无梳状平行线、分支从节点自身端口出发、页面卡片视觉权重最高、卡片三段结构完整且标题单行截断、逐卡预览不超出卡片、入口小旗与方向一眼可见、标签样式统一且贴线、图例一行且只解释图形、目录与控件组不压节点、当前流程只由目录选中态表达、无空白节点、界面上没有调试数据。全图字号记录为参考值。每条不通过项附截图位置 |
| 真实点击 | 对卡片内每类控件（info、重置场景、场景切换、出口、目录项、控件组按钮）做一次真实鼠标单击，不用脚本 click 代替，以免掩盖指针捕获和层级遮挡问题；真实打开一次卡片里的 Dialog，确认它显示在画布之上；悬停出口，确认临时虚线或去向提示正确 |
| 连线显示 | 默认“全部”且主路径高亮；“全部 / 主路径 / 仅异常分支”筛选结果正确；选中节点高亮相邻边，空白恢复当前筛选 |
| 内容布局 | 短、长、错误提示及实际最大字段场景自然增高，到上限只有内容滚动；标题操作区可见；长 URL/文本不横向溢出，控件弹出层不被意外裁切 |
| 场景语义 | 逐项核对必填、URL/密码/多行/选择控件、帮助链接、按钮校验与结果；实际存在的加载、待处理、空态、不可用、失败、取消、重试可触达 |
| 步骤与能力 | 适用时逐业务对象核对步骤内容、完成依据和二维码支持证据；无依据的分支不出现 |
| Fake 边界 | 开关两态符合项目约定；操作期间观察请求、导航及可变存储，无真实授权/凭证提交或业务写入；仅有 iframe 不算此项通过 |
| 评论与迁移 | 评论修复证据与节点一致；逐入口回核覆盖。已授权迁移须从业务入口实操，未迁移列明，不以画布截图替代 |
| 项目检查 | 执行项目适用的类型检查、lint、构建及相关测试，记录命令和结果；失败注明本次引起还是已有问题，必要失败不能标完成 |

截图用于视觉证据，不能代替交互验证。内置浏览器面板被隐藏时，iframe 内的 ResizeObserver 可能不触发，预览会一直停在骨架；需在面板可见时测试。检查工具不可用时说明未验证项，不伪造实测；可继续完成其他已授权工作。

修复后重跑失败项及受影响回归，不无差别重复已通过检查。收尾关闭为验证创建的命名浏览器/Playwright 会话，即使验证失败也执行；删除本次临时产物和停止本次启动的临时服务，不关闭用户已有会话或服务，不删除正式证据和画布资源。
