# 验收矩阵与证据

初始化执行基础设施行；新流程/比较集合执行全部适用场景；局部修改根据共享影响范围选择回归。先标明 `flow` / `tiles`，混合任务分别验收；共用行两者执行，标注流程/平铺的行仅对应模式执行。源码记录验收可查看性与证据，不套用真实预览交互通过。每项记录条目/场景 ID、操作、期望、观察结果及截图/日志/检查输出位置；不适用说明理由。

| 范围 | 操作与可观察的通过条件 |
| --- | --- |
| 依赖与可复现性 | 记录实际使用的依赖版本，确认清单、锁文件和安装结果一致；本次新增依赖有相应授权且能被导入、通过项目构建。与 canvas-kit 参考版本不同不构成失败 |
| 共享展示代码 | 初始化及组件变更均核对[共享展示契约](workflow.md#从初始化建立同一套展示代码)：实际页面、画布和独立预览引用同一组件导出与样式文件，附引用路径证据；同一场景输入下布局、字段与视觉状态一致，容器差异有依据。确认展示修改同时影响实际页面和预览，预览仍无真实副作用；仅截图相似或共用基础控件不足以通过。新设计无实际对应时记为待接入，不宣称实际入口已验证 |
| 入口与覆盖（流程） | 直达并刷新 `/<业务路由>/design-canvas` 及每个受影响流程的 `?preview={name}`，旧地址重定向到新路径且 query 原样保留，预览只含该流程且可从入口走到各结果，未知名称显示空态；从各实际调用方核对已用组件；覆盖表无未解释遗漏，提议与不可达旧代码明确分开 |
| 同时交互与隔离 | 至少两个预览并列，分别输入/选择、打开菜单、Tab 与 Esc；A 的状态、Portal、遮罩及关闭不干扰 B，父画布可继续操作 |
| 关闭重开 | 对适用场景用关闭图标、取消、完成等真实出口退出并重开；状态保留/重置符合定义，重复操作不积累监听器或卡死焦点 |
| 拖拽命中区 | 标题可拖，内容输入、选择文字、菜单与按钮不拖节点，标题栏内的控件单击一次即生效；缩放后跨 iframe 边界拖动并释放/取消，节点不跳跃、不粘住，内容仍可操作；仅流程模式的拖动几何自检：对每个流程做「每个节点 × 若干方向小幅拖动」，三项全过——点位移不超过拖动距离、无斜线段、原本共点的边拖动后仍共点（参考实现 `checkDragGeometry`）；再挑一个扇出节点、一个多入边节点真实拖动复测，扇出主干、合并末段、端口进入方向与标签位置都保持 |
| 视口与聚焦 | 右下角控件组的放大、缩小、适配全图（Shift+1）、缩放到选中卡片（Shift+2）与重置布局按定义工作，不可用时置灰；目录收起、展开后画布重新适配；节点/条目内点击保留输入焦点，流程模式淡化无关边，空白恢复；内容滚动不带动画布 |
| 动态连线（流程） | 初次测量、拖动、内容增高及窄/宽视口后逐流程满足 [连线指标](initialization.md#连线指标)：主路径零交叉、边不穿节点、标签零重叠、每边至多 2 个拐点、无回指边；有去向的返回、取消以底栏出口呈现，悬停显示的去向正确，原地操作不列；跨流程无连线 |
| 视觉呈现（流程） | 不看代码，用默认打开后的截图并与 [canvas-kit](../assets/canvas-kit/) 的 HTML 标准件并排对照，按 [画布呈现规范](canvas-presentation.md) 逐条判断：首屏看到完整流程、主路径在同一基线直线推进、扇出无梳状平行线、分支从节点自身端口出发、页面卡片视觉权重最高、卡片三段结构完整且标题单行截断、逐卡预览不超出卡片、入口小旗与方向一眼可见、标签样式统一且贴线、图例一行且只解释图形、目录与控件组不压节点、当前流程只由目录选中态表达、无空白节点、界面上没有调试数据。全图字号记录为参考值。每条不通过项附截图位置 |
| 真实点击 | 对卡片内每类控件（info、重置场景、场景切换、出口、目录项、控件组按钮）做一次真实鼠标单击，不用脚本 click 代替，以免掩盖指针捕获和层级遮挡问题；对真实预览打开一次卡片里的 Dialog，确认它显示在画布之上；流程模式另验出口悬停的临时虚线或去向提示正确 |
| 连线显示（流程） | 默认“全部”且主路径高亮；“全部 / 主路径 / 仅异常分支”筛选结果正确；选中节点高亮相邻边，空白恢复当前筛选 |
| 清单与目录（平铺） | 遍历收集清单，逐项定位卡片及独立查看入口（含源码记录），检查刷新、未知 ID、分页/搜索/虚拟化后的可达性；目录模块数、清单条目数及各自筛选数按同一单位与事实源一致，Dialog/Sheet 独立 Section Group，组下直接业务模块 Sidebar Item，无文件夹/折叠树或实例级主目录，无虚构侧栏导入。分别统计源码记录、可操作原组件预览、已验证条目/场景；引用可达或样本不能填为完整交互覆盖 |
| 有序比较（平铺） | 打开模块后每个流程/相关场景组一行，有依据的步骤从左到右且不自动换行；独立场景单卡成行，未知顺序有标记。重置后行顺序、行列间距及卡片/标题/预览顶端对齐；实测槽位不重叠，不改变原组件尺寸来凑等宽。同组预览比例一致，记录比例及画布缩放；宽组件不被初始 iframe 压缩，选中缩放和独立预览能读实际内容。默认视口可读且全部条目可定位/独立查看，无伪造连线、入口旗、判断、流程出口或连线筛选 |
| 预览稳定尺寸（共用） | 按 [视口规则](component-design.md#预览视口与稳定尺寸) 核对响应式留白与回算；在初次加载、场景切换、校验增高、重置及窄/宽视口后等待字体/过渡与宽高稳定，记录连续采样。验证没有持续缩小或振荡、声明宽度未压缩、Sheet 内容及底部操作完整可点击/可滚动到。瞬时矩形或固定留白推算不能单独通过；超时/裁切记失败 |
| 国际化（共用） | 目录、标题、场景标签、说明、能力状态、提示及空态沿用项目翻译机制；切语言后稳定 ID 和查看入口保持，长译文不遮挡操作。项目无国际化机制时按约定语言检查并记录不适用理由 |
| 内容布局 | 短、长、错误提示及实际最大字段场景自然增高，到上限只有内容滚动；标题操作区可见；长 URL/文本不横向溢出，控件弹出层不被意外裁切 |
| 场景语义 | 逐项核对必填、URL/密码/多行/选择控件、帮助链接、按钮校验与结果；实际存在的加载、待处理、空态、不可用、失败、取消、重试可触达 |
| 步骤与能力 | 适用时逐业务对象核对步骤内容、完成依据和二维码支持证据；无依据的分支不出现 |
| Fake 边界 | 开关两态符合项目约定；操作期间观察请求、导航及可变存储，无真实授权/凭证提交或业务写入；仅有 iframe 不算此项通过 |
| 评论与迁移 | 评论修复证据与节点一致；按模式回核入口或条目/场景覆盖。已授权迁移须从业务入口实操，未迁移列明，不以画布截图替代 |
| 项目检查 | 执行项目适用的类型检查、lint、构建及相关测试，记录命令和结果；失败注明本次引起还是已有问题，必要失败不能标完成 |

截图用于视觉证据，不能代替交互验证。内置浏览器面板被隐藏时，iframe 内的 ResizeObserver 可能不触发，预览会一直停在骨架；需在面板可见时测试。检查工具不可用时说明未验证项，不伪造实测；可继续完成其他已授权工作。

修复后重跑失败项及受影响回归，不无差别重复已通过检查。收尾关闭为验证创建的命名浏览器/Playwright 会话，即使验证失败也执行；删除本次临时产物和停止本次启动的临时服务，不关闭用户已有会话或服务，不删除正式证据和画布资源。
