# 模式选择与边界走查

用于用途/工作流变化后的语义回归。以下为本次维护者基于实际文档的自查，不是独立模型回放或宿主应用实测。

| 请求 | 应选择与读取 | 本次走查结论 |
| --- | --- | --- |
| “把批量导入的选择文件、字段映射、校验与提交结果放到可操作画布，检查取消和分支。” | `flow` → workflow → modeling；复用就绪能力，变化范围内读取组件设计、流程呈现与验收。按真实入口建边/出口、适用 ELK 和连线指标 | 入口明确命中流程模式；既有节点、判断、出口和覆盖表规则仍适用，无需先建立平铺条目模型 |
| “收集各模块的 Dialog 和 Sheet，方便制定统一规则；每个模块里一个相关流程一行。” | `tiles` → workflow → design-tiling；类型 Section Group 下直接模块 Item，无文件夹/树；相关步骤有证据则从左到右，独立场景单卡成行，未知顺序明确标记 | 入口命中平铺而非空边流程图；读得到独立模型/布局及模块侧栏参考，全部收集条目可查看，源码记录不冒充真实预览 |
| “只拿几个代表场景比较，但保留完整收集记录。” | `tiles`；标明样本、筛选及未预览列表，模块视图/清单仍可逐项查看其余源码记录；报告样本与完整范围的不同分母 | 文档允许抽样比较，同时阻止样本覆盖偷换为完整交互覆盖；若要求全部原组件预览，缺口必须记为未完成 |
| “既要检查导入分支，也要并列比较其中的弹层尺寸。” | 明确分开的 `flow` / `tiles` 视图，稳定组件/场景 ID 映射；流程验边和可达性，平铺验逐行顺序、对齐及清单 | 混合模式不把条目顺序变成连线，也不以平铺通过代替流程验收；共用展示和隔离能力，不新增迁移授权 |
| “已有平铺中一个 Sheet 不断缩小并裁掉底部按钮，只修这一处。” | 就绪记录、受影响组件/桥接、component-design 的稳定尺寸规则、verification 的共用/平铺项；响应式留白回算、有界稳定采样和底部点击 | 不要求通读无关流程模型、不触发 ELK 或依赖升级；修复与重验属于原授权范围，首报/瞬时矩形不能通过 |
| “画一个普通流程示意图”或“改一个 Dialog 的圆角” | 不触发本 Skill 的多组件可操作画布工作流 | description 的排除边界仍保留；不要求为单弹层样式修正搭建画布 |

必要缺口只阻塞对应能力；保留可用部分及证据。画布认可不自动接入正式业务，完整会话已有明确迁移授权才执行指定入口迁移；不为模式选择、修复或重验重复请求确认。
