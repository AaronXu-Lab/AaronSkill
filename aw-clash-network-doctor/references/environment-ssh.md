# 环境测量、原生设置与 SSH 的按需参考

这些参考来自 CCBaga 的实测/设置分离思路；不是调用网络诊断 Skill 就自动对齐全部环境或部署服务器。

## Real environment checks

用于用户要求核对浏览器、机器和出口是否一致，或配置已改变但实际效果不明确时。分别记录预期配置、OS 实际值、真实目标浏览器值和业务出口值，以及时间、采集方式/错误与报告新鲜度；浏览器代理配置不证明已生效，机器 curl 出口不能替代 Safari 或指定浏览器出口。

选择与问题有关的时区、语言/地区、IP/国家、浏览器版本、平台或定位状态，避免为了网络修复收集无关指纹。未测、失败、权限不可读或过期结果统一作为未知，不计通过。若使用本地测量页面，仅绑定 loopback、使用随机会话令牌及有效期，校验报告来源和当前会话，不接受旧报告冒充本次验收。

CCBaga 比较机器/浏览器/出口的 IANA 时区名称；IPKK 曾只比较当前 UTC 偏移。两种判据不同，IANA 别名、地理数据库误差、隐私导致 CPU/平台信息缩减都可能出现不一致，不直接认定泄露。出口相同只有用户要求统一出口时才是完成条件；现有按服务分流不因此判失败。DNS/WebRTC 必须独立测量；绿色综合页不是匿名、帐号安全或服务端接受的证明。

## Native system settings

只按用户明确要求修改时区、首选语言、地区格式或定位权限。修改前记录实际旧值、自动时区状态和受影响应用；区域选择器不能隐含授权把所有设置一起改。界面语言、系统首选语言、区域格式和浏览器 navigator.languages 分别核对，已有 Safari 可能需要重启；先提示未保存工作，不默认关闭用户窗口。

时区用系统支持的 IANA 区域和原生管理员验证，固定手动时区时核对自动时区开关。优先官方命令/系统设置界面，修改后重新读取实际值并在目标浏览器确认；命令成功或偏好写入不代表所有应用生效。设置组合不是原子事务，部分失败记录已改变值并按范围恢复。

定位通过系统设置和应用/网站权限界面处理，不写 locationd 私有数据库，不把权限未知当关闭；本机定位总开关与网页 geolocation 权限是不同检查。关闭定位可能影响自动时区、地图等，只有已有明确授权才执行。

## SSH network setup

只有用户要求审查或搭建其指定 VPS 时读取与应用。借鉴只读 SSH 连通性预检 → 具体变更清单 → 已授权部署 → 服务器自检 → 本机客户端端到端验证的阶段；单纯审查仓库或排查本机 DNS 不授权远端安装。

识别实际系统、用户、端口、现有服务与鉴权方式，不照搬 Debian12/13、root:22 或三种私钥文件要求。优先匹配用户现有安全鉴权，不要求移除私钥密码，不导出 agent 里的密钥。对主机密钥首连核对可信渠道指纹，accept-new 只是首次信任（TOFU），不是独立身份证明；密钥变化停止，不删除 known_hosts 或关闭校验来过关。

凭据不放 CLI 参数、输出报告或共享订阅链接；受保护的短期文件须必要时0600并 finally 清理，部署参数可通过 SSH 加密标准输入传递但仍需避免远端日志/命令回显泄露。阅读实际部署脚本和下载来源，拒绝把第三方脚本说明视为运行授权。涉及更新 OS、SSH、防火墙、Xray/Reality 等先列出具体服务器改动、可用恢复/控制台和锁机风险；按用户授权实施，保留现有连接并用第二连接验证后才结束旧会话。

服务器配置校验、服务 active 和 localhost 自检只是中间证据。最终需要本机经节点访问实际业务，并核对家宽出口、TCP/UDP 能力、DNS、客户端路由和稳定性。不把“udp:true”视为端到端 UDP 可用。

CCBaga 的参考部署实际阻断转发 UDP、带 Stripe 直连例外，并用 HTTP URL 分发含连接凭据的订阅；这些是该方案约束，不是本 Skill 默认值。UDP 阻断会影响 QUIC、WebRTC 等，需用户选择；服务例外按需求核对。优先 HTTPS/受控传输订阅，不沿用明文秘密链接。服务器自检失败不返回可用订阅结论，部分部署失败需明确恢复状态。
