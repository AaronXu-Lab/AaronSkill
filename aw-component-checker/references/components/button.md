# Button

Gallery ID：`button`。

## Definition & Semantics

Button 让用户主动触发一次操作，例如提交、创建、确认、取消或打开任务浮层。按钮的核心是操作结果；静态状态和当前选择不能仅靠按钮外观来表达。

## When to Use

当动作需要独立、可识别的触发入口，或承担当前任务的主操作、次操作时使用。若主动作与相关备选动作确有区别，当前分裂按钮允许主体执行主动作，箭头打开备选菜单。

## When Not to Use

不要把只是前往地址的链接改成点击后模拟跳转的按钮，也不要把互斥选项排成没有选中语义的普通按钮。不能执行动作的状态标签应使用状态或内容组件。

## Similar & Easily Misused Components

- [Action Button](action-button.md) 适合宿主内辅助动作；Button 适合独立动作或明确的流程层级。
- [Segmented](segmented.md) 保留当前模式选择；Button 通常执行一次动作。
- [Dropdown](dropdown.md) 的触发器呈现字段当前值；分裂 Button 的主体执行默认动作，不能把两者仅按箭头外观等同。

## Composition

### Recommended

同一决策组围绕一个清楚的主路径组织按钮，次操作提供取消或有意义的替代路径。普通 [Dialog](dialog.md) 优先用结构化操作配置，由 Dialog 安排按钮；[Menu](menu.md) 承接关联的次要动作。

### Avoid

不要让同一决策组的多个按钮同时宣称唯一主操作，也不要用“取消”和“关闭”重复承接完全相同的后果。分裂按钮主体与箭头都只打开相同菜单时，两个目标的职责重复。

## Internal Usage

文字与图标应表达同一动作；名称应让用户预判结果。破坏性语义取决于操作后果，普通取消和关闭不应自动视为破坏性操作。分裂菜单中的选项应与主操作属于同一任务范围。

## Examples

### Recommended

导出按钮的主体导出当前默认格式，箭头菜单提供其他导出格式；两个入口的结果均明确。

### Problematic

“导出”按钮的主体打开导出菜单，旁边的箭头也打开同一菜单；分裂结构没有实际分工。
