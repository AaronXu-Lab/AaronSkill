# Code Block

Gallery ID: `code-block`

## Definition & Semantics

Code Block 提供代码或需要保留原文结构的片段的阅读与复制。高亮帮助理解内容，换行与大小调整改变阅读呈现；这些能力都不代表内容可以编辑或执行。

## When to Use

用户需要阅读代码、配置、命令或原样复制的文本片段，并且原始内容及换行具有实际意义时使用。非代码片段也需具备清楚的原文读取或复制需求，不能只因想获得一个容器而使用。

## When Not to Use

需要输入、修改或保存文本时，应使用编辑控件。普通说明文字没有原文复制或结构保留需求时，不必包装成 Code Block；也不要把语法高亮按钮解释为运行、校验或修复代码。

## Similar & Easily Misused Components

- [Input Area](input-area.md) 收集多行输入，Code Block 呈现已有内容供阅读和复制。
- [Lightbox](lightbox.md) 提供文件预览上下文，Code Block 只是其中一种内容结构；普通片段阅读不必升级为全屏文件预览。
- [Message Answer](message-answer.md) 组织完整回答，Code Block 只组织回答中的原文片段，不能代替解释、结论或附件关系。

## Composition

### Recommended

在说明、Message Answer 或详情分区中呈现代码片段，由邻近内容说明片段用途。需要编辑时，以独立操作进入 Input Area 等适当编辑结构，并区分已保存内容和草稿。Lightbox 展示代码文件时，可以复用 Code Block 的阅读和复制能力。

### Avoid

不要让外层“复制代码”与内层复制按钮指向不同内容，却使用同一个名称。若产品增加运行操作，应明确其独立行为和范围，不能复用高亮或复制入口暗示代码已执行。不要让只读片段和编辑草稿保持两套无法区分的内容来源。

## Internal Usage

code 是阅读和复制的同一份原文，语言标识应与实际内容一致。高亮模式只影响呈现，不改变复制结果；不支持某种语法或高亮失败时，应保留可阅读的原文，不能将其当作内容错误。复制反馈只能在实际复制结果确认后表达成功，不能根据点击本身判断。

## Examples

### Recommended

详情页展示可复制的配置原文，用户通过独立“编辑配置”入口修改；保存后阅读区更新到同一份已保存内容。

### Problematic

用户点击语法高亮按钮后，界面显示“运行成功”，实际上既未运行代码，也没有得到执行结果。
