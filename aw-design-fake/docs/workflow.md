# AW Design Fake 文本工作流

本文是执行事实源，workflow.svg 是面向人的可视化投影。按本次任务读取相应章节与链接；不要求每次通读全部参考资料。

## 范围与现状

处理前端原型或设计验证中的占位操作、占位内容和可关闭演示状态。单元测试 mock、网络层 mock、正式生产功能不采用本流程；说明边界后按实际任务继续，不把“不使用本 Skill”解释为停止整个任务。

沿用完整会话里的工作区、共享目录、模式和授权。读取适用于本次改动的项目约定，搜索任务附近已有入口；已经读过且仍有效的内容可复用。没有成文约定不阻塞，不为局部接入通读全部设计文档。

仅审查时只读取、运行适用的 `--check` 并报告差异与未验证项，不初始化、同步或修改文件。修改任务按以下分支完成实现、验证和修复，不在第一版后默认等待 review。

## 选择接入路径

- 仅展示源码、尚无 bundle 且已有 Gallery / 原型 fixture：读 [源码消费约定](../references/code-demo.md)，将唯一文本资产接入已有入口，直接验证保真，不初始化 bundle 或运行模拟。
- 其他项目接入：运行 `node <Skill目录>/scripts/fake-bundle.mjs --project-root <项目根目录> --check`。`current` 复用现有入口；未初始化、缺失、过期、漂移或 `newer` 时才读 [bundle 接入与同步](../references/bundle.md) 的对应分支。
- 全局字段不足或任务明确维护 Skill：读 [维护约定](../references/maintenance.md)。项目接入授权不自动覆盖安装 Skill；先核对已有授权，只有缺少完成当前需求所必需的授权时询问，不重复确认已授权事项。不能用手改项目生成文件绕过统一资产维护。

## 选择最小 fake 层级

“用 fake 方法”也需要判断实际用途，不泛化为任意模拟实现。

### 占位操作

在真正发生的用户事件中调用 bundle 导出的 `showFakeSonner()`。不自写 toast 文案，不用 console、空回调或无反馈点击代替。可保留需求明确要求的瞬时选中、展开或 tab 状态，但不制造持久化成功状态。重复选择当前值、disabled 或未产生操作的事件不重复提示，除非用户明确要求。真实能力接入时应能直接替换 handler，无须重写展示结构。

### 占位内容

先查所需语义的 `FAKE_DATA` 字段，按 [占位内容](../references/content.md) 复用统一值或业务域 fixture；不另造同义副本。源码的完整文本、高亮与复制按 [源码消费约定](../references/code-demo.md)。

### 演示状态

完整对象、列表详情联动或流程推进按 [演示状态](../references/simulation.md) 使用业务域 fixture 与统一 selector；关闭时所有读取入口一致移除演示数据。

## 真实契约隔离

fake ID 不发往真实后端，模拟只写本地演示状态；来源或明确身份用于区分真假对象。真实请求不携带 fixture、preview 等演示字段，不改正式工程、BFF、DTO、API shape、auth 或 service 契约。后端缺字段默认不展示对应区块；只有需求明确要求 overlay 才在展示层叠加，并随演示开关完整关闭。

不在标题、值、Badge、说明或操作文案里添加「演示」「Fake」「Mock」「测试」「占位」等来源标记。真假边界放在代码目录、类型、adapter、selector、ID 和请求隔离中。源码是展示文本，不执行。

## 验证与交付

选择与改动对应的检查：

- 占位操作：有效动作触发统一提示，重复/disabled 行为符合需求，没有网络或真实持久化副作用。
- 占位内容：展示值来自唯一数据入口；源码普通/高亮/软换行和复制均保留完整原文，无执行副作用。
- 演示状态：按关→开→关→开检查相关列表、详情、计数、关联读取与非 Hook getter；关闭时 fixture 为 0、真实数据不变，开启后可恢复。
- 修改项目且已有 bundle：结束前重跑 `--check`，应为 `current` 或明确记录的兼容 `newer`，且 adapter 存在并完成实际接线。仅源码 fixture 分支记录唯一消费入口，不强制创建 bundle。
- TypeScript 或状态逻辑改动：运行项目类型检查；新流程或非平凡交互按项目约定做浏览器验证。维护 Skill 则按 [变更与检查映射](../references/maintenance.md#验证) 选取检查。

在已授权、隔离且无生产访问的本地项目中，继续修复本次改动引起的失败并重验受影响项。缺少依赖、授权或必要信息时报告具体缺口及已完成部分，不能把未验证行为标为通过。

交付最小可移除实现或只读审查报告，说明采用的分支、唯一消费入口、涉及的版本、验证结果与未完成项。
