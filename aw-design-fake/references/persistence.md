# 缓存 Fake：临时模拟后端持久化

仅在 Design Demo 尚未接入后端、产品最终应由后端跟随账号保存，且需要刷新后继续演示时读取。这里的“缓存”是浏览器本地存储暂代后端持久化，不是通用缓存治理，也不是静态 `FAKE_DATA` 的另一种放置方式。沿用主工作流的真实契约优先与授权边界。

## 先判断数据职责

| 情况 | 处理 |
| --- | --- |
| 最终由后端按账号保存，Demo 暂未接入 | 缓存 Fake；例如置顶及顺序、引导关闭进度、应跨设备同步的用户偏好。 |
| 已接入真实 API，为复用响应或离线读取而缓存 | 真实接口结果缓存；遵循现有数据层，不转成 Fake，不在这里扩展缓存策略。 |
| 产品本来只需本机保存 | 合理本机状态；例如仅当前设备的面板宽度，保留原职责。用户偏好是否属于此类取决于产品要求。 |
| 只需本次演示中推进，刷新可以丢失 | 纯内存演示状态；按 [演示状态](simulation.md)，不增加持久化。 |

先盘点每个区域现有读写契约。已接入后端的区域不能因响应为空、失败或全局填充开启而改用本地 Fake；若另需模拟，只能进入数据与写入路径隔离、可退出的独立场景。缺少未来后端细节不阻塞 Demo，但不得编造 endpoint、DTO、同步协议或权限能力。

## 项目统一注册，业务域持有数据

复用项目现有 store、repository 或 adapter，建立一个可枚举的模拟持久化注册表或等价统一入口。至少记录下列内容，定义可分布在各域并集中导出；集中管理规则不等于把全部业务对象、fixture 和状态搬到一个大文件：

| 注册内容 | 要求 |
| --- | --- |
| 标识、用途与业务归属 | 稳定项目 ID、对应业务域和消费接口；指出目前替代哪项未来后端保存职责。 |
| 身份、租户与资源作用域 | 按实际数据归属选择必要维度；账号级不无故按资源拆分，资源级不能只按账号隔离。所需身份未知时不退回共享账号键。 |
| 格式版本与初始值 | 单项 schema 版本、校验方式、默认值或 seed 来源；seed 可组合域 fixture，但用户修改后的记录不是 `FAKE_DATA`。 |
| 生命周期与恢复 | 退出登录保留或删除、重置范围、旧版本迁移或重建策略、异常回退与已保存数据的清理规则。 |
| 替换边界 | 稳定的业务读写接口、当前本地实现位置、未来应替换的后端持久化职责。 |

模拟存储使用项目专属、可识别的独立命名空间，键中以无碰撞编码包含项目 ID、注册项及必要身份/租户/资源维度；schema 版本可在键或记录中表达。与真实接口缓存、本机偏好及凭证存储分开，任何清理只处理注册范围内的模拟键，禁止 `localStorage.clear()` 或按宽泛前缀删除其他数据。不存真实 token、密码、密钥；作用域可使用非敏感标识，不能把凭证当作身份键。

页面调用有业务语义的接口，如 `pinItem`、`reorderPinnedItems`、`dismissGuide` 或 `savePreferences`；存储序列化、读写与异常处理集中到项目模拟持久化实现中，不在组件各处直接操作 `localStorage`。消费接口与实现解耦，遵循项目同步/异步习惯，允许未来替换为远端实现；不为迁移预先伪造 HTTP 契约。业务域负责有效值、状态与关联更新，底层只负责约定的持久化规则。

共享 bundle 仍提供通用文案、内容和占位操作，项目自有注册入口与存储实现不写入受管 bundle 文件，也不强塞进只负责提示和资源 URL 的 `adapter.ts`。按项目架构选择最小实现，不默认增加数据库、通用缓存框架或新的全局代码包。

## 开关、身份和生命周期

实现前明确有效演示条件：区域尚未接真实契约，或处于显式独立演示场景；存在全局假数据开关时还须开启，独立场景另受进入/退出状态控制。所有公开 selector、非 Hook getter、action 和持久化 adapter 共用当前条件，不能只在 JSX 层挡住，也不能在模块加载时读取或写入默认值。

- **关闭开关或退出演示**：停止模拟读取、seed 和写入，清除当前内存中的演示投影并返回主工作流规定的真实数据或稳定空值。关闭后再调用旧 action、订阅回调、延迟保存也不能落盘或泄漏演示结果；有排队操作时取消或以身份/场景代次使其失效。关闭不等于销毁已保存模拟数据，默认保留；重新启用仅恢复当前作用域记录。清理必须走独立的显式重置操作，不能被关闭后的普通 action 绕过禁写规则。
- **刷新**：仅在演示有效、作用域完整时读取并校验当前记录。没有记录时使用已登记默认值或 seed；是否立即写入 seed 由注册规则决定，禁止在关闭状态自动 seed。
- **切换账号/租户/资源**：使旧作用域内存和未完成操作失效，随后在演示有效时加载新作用域。不得短暂展示旧身份数据，不把旧作用域的延迟写入保存到新键；多标签页订阅如存在也须检查当前作用域和开关。
- **退出登录**：立即停止账号模拟读写，移除当前内存状态及待处理操作。注册规则需明确保留以便再次演示，或删除该账号模拟记录；没有产品要求时默认保留，不能回退到共享匿名键。保留数据只可在重新进入相同身份且开启演示后恢复。
- **显式重置**：提供可定位的开发/演示操作，说明重置当前项、当前作用域还是全部已登记模拟数据；只删除授权范围的模拟键。关闭时允许用户显式执行专用清理，但不重新 seed、不恢复演示读取，也不碰真实缓存和本机偏好。
- **不可用、损坏、旧版本**：捕获访问/配额/序列化异常，校验记录结构与版本。默认回退到当前作用域的内存模拟并说明无法跨刷新保存，不冒充持久化成功；不能显示来源标签的约定仍适用，可用普通保存失败反馈。损坏数据按注册规则丢弃或隔离后重建；旧版本只有明确迁移函数时迁移，否则只重建该模拟项。不读取未知格式充当有效数据，不静默清空全部存储。不会失败的普通刷新仍应恢复已保存修改。

真实配置、授权与生产操作仍按真实契约执行。演示 ID 和字段不得进入真实写接口，包括未来切换 adapter 时的残留状态；本地模拟存储不能被自动当作真实接口的失败兜底。

## 接入真实后端时替换或移除

1. 核对真实契约和业务语义，将稳定业务接口的实现替换为真实 store/repository/adapter，连接真实读取、保存及状态反馈；保留尚未接入区域的明确边界。
2. 停用该项模拟路由、selector、seed、订阅与排队写入，清除内存中的演示对象，重新加载真实状态；移除未再使用的注册项及模拟实现。仍需独立演示时保留显式隔离入口，不能降级真实区域。
3. 对废弃模拟键提供定向清理或记录保留策略；只清理本项目该项模拟数据。默认不向后端上传、合并或补写本地模拟记录。若用户另行要求迁移，应独立确认数据与真实身份映射、冲突规则和写入授权。
4. 验证页面无需重写展示逻辑即可使用真实实现，真实空/加载/失败态有效；演示 ID、旧内存及本地记录均不能进入真实写接口。没有可用后端时交付替换位置与步骤，不虚报已完成远端联调。

## 验证与交付

在授权项目中验证本次注册项的可观察行为，使用适当的状态测试与项目类型检查；有非平凡交互时按项目约定做浏览器验证。至少覆盖：

| 检查 | 通过标准 |
| --- | --- |
| 保存与刷新 | 修改后同身份同作用域刷新恢复；无记录时按登记值初始化。 |
| 身份隔离 | 账号、租户及资源按登记归属隔离；切换与退出登录后无旧数据闪现或跨域延迟写入。无需的作用域维度标记不适用。 |
| 关→开→关→开 | 关闭和退出场景时普通读写入口不访问模拟存储，fixture/seed 为 0、旧回调无效；真实数据不变，重新开启恢复当前作用域已保存记录。 |
| 重置与退出 | 关闭不删除记录；显式重置只影响所选模拟范围；退出登录遵循登记策略；预置真实缓存、本机偏好哨兵值均不变。 |
| 存储异常 | 禁用存储、读写失败、配额不足、损坏与旧版本均有登记的恢复结果，不崩溃、不假报已保存、不扩大清理。 |
| 真实边界与替换 | 真实区域在两种开关状态下均保持真实空/加载/失败等契约；观察请求确认演示 ID 无真实写入；核对替换步骤无默认上传路径。 |

交付注册清单（用途、业务归属、作用域、版本、默认值/seed、清理规则及待替换职责）、稳定消费接口与本地实现位置、开关/退出登录策略、重置入口、后端替换/移除说明，以及逐项通过或未验证证据。仅文档维护时走查这些要求，不把走查称为项目运行验证。
