# 方法参考与取舍

维护或研究本 Skill 方法来源时读取；日常执行无需加载这些上游 Skill，也不要求安装它们。以下为方法层面的综合改写，未捆绑上游代码、模板或运行服务。

- [rjs/shaping-skills — shaping](https://github.com/rjs/shaping-skills/blob/main/shaping/SKILL.md)：借鉴问题与方案双向塑形、需求与方案分离、适配检查；不沿用固定编号体系、完整表格反复输出、二元判定、实现切片与多层工程文档。
- [mattpocock/skills — grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)：借鉴按决策依赖分轮追问、查证事实、提供推荐并保留用户决定权；不要求一次问完所有可问问题、遍历全部分支或强制使用子代理。
- [obra/superpowers — brainstorming](https://github.com/obra/superpowers/blob/main/skills/brainstorming/SKILL.md) 与 [Visual Companion](https://github.com/obra/superpowers/blob/main/skills/brainstorming/visual-companion.md)：借鉴按问题选择视觉表达、保真度与问题匹配、通过反馈迭代；不沿用专用服务、固定审批链、自动提交文档或强制进入实现计划。

本 Skill 补充：多种成熟度输入、竞品 UI/UX 逻辑的证据化分析、初始探索方式的用户选择、面向初版生成的简报，以及主方案确认与后续状态覆盖的边界。外部规则更新不自动覆盖本地约定；维护时重新评估适用性。
