# 动画设计轴回归

仅在维护本 Skill 的正式轴筛选、交互比较或相关路由时使用。判定事实源为 [正式展示筛选](../references/design-axes.md)，呈现与验收见 可比较示例、验证与恢复；本文件不建立组件专属例外。

| 测试请求与给定证据 | 应选择的路径与判定 |
| --- | --- |
| “审查 Collapsible 的 animated；true 有展开／收起动画，false 即时切换，但两张终态截图相同。” | 入口 → 正式展示筛选；保留 animated 正式设计轴，撤回以纯动画机制为由移出的建议。按 可比较示例 用真实展开／收起比较各值，验证与恢复 记录过程差异；不要求终态不同。只读审查不修改项目。 |
| “另一个组件的 motion 属性在滑入与淡入间切换，请增加 Gallery 比较。” | 同样按 正式展示筛选 纳入可感知的动画设计差异；新增轴先读 组件命名与映射 命名映射，再按 可比较示例 呈现，不能把规则限于某组件或 animated 名称。 |
| “公开的调度参数只改变内部批处理方式，设计结果与动画过程均无可感知差异。” | 按 正式展示筛选 排除；公开、可配置或与动画有关均不能单独证明设计价值。不为展示内部机制新增组件参数。 |
| “截图一样，所以删掉所有动画轴。” | 静态证据不足以支持排除，补查契约和实际触发过程；无法观察时标记未验证，不把未验证等同无设计价值。 |
| “父级组合已经有动画，子组件页无需 animated 对比。” | 按 父子展示 独立判断子轴价值；父级展示不替代子级矩阵，有独立动画比较价值则保留。 |
| “只调整现有 size 轴顺序。” | 仍按 页面／属性规则 局部排序，无需重选动画轴或运行动画验收。 |

4.6.0：维护者逐项走查入口 → 工作流 → 正式展示筛选、可比较示例、父子展示、验证与恢复。正例覆盖启用／关闭与不同动画形式，反例覆盖内部调度，证据不足和父子展示分别处理；组件页面的 Usage 必有规则未改动。此记录为文档语义走查，未做独立模型回放或真实项目 UI 交互测试，不代表来源项目已修复。
