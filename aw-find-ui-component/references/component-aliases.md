# Component Aliases

Use the canonical term as an additional search query when a request matches one of its aliases. Do not treat aliases as proof that two components have identical behavior.

| Canonical term | Common aliases |
|---|---|
| message | chat message, conversation message, message row, chat bubble |
| alert | callout, notice, inline notification, status message |
| toast | transient notification, snackbar |
| dialog | modal, modal dialog |
| drawer | bottom sheet, side panel, slide-over |
| combobox | autocomplete, searchable select |
| command | command palette, action search |
| select | dropdown select, picker |
| empty | empty state, no results |
| progress | progress bar, loading progress |
| spinner | loader, activity indicator |
| tabs | tab list, tabbed navigation |
| tooltip | hint, hover help |
| popover | anchored overlay, floating panel |
| scroll area | custom scrollbar, scroll container |
| data table | sortable table, filterable table, data grid |
| pagination | pager, page navigation |
