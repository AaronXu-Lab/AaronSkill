# 稍后阅读内容处理工作流

本文档是执行 AW Mail Read Later 时优先读取的文本工作流，也是 `workflow.svg` 的语义事实源。SVG 是与本文档同步的可视化投影。

## 输入与产物

- 输入：明确涉及 Outlook `Read Later` 文件夹或当前推荐内容的请求，以及用户当前情境、时间与反馈。
- 产物：一次一项的内容推荐、阅读处理结果，或经确认的归档/排除动作；运行数据保存在当前项目索引中。

## 执行步骤

1. 在当前项目初始化并读取 `data/aw-mail-read-later/` 索引；失败时不访问网页或推荐内容。
2. 定位显示名称恰好为 `Read Later` 的 Outlook 文件夹；多个同名文件夹时由用户选择。
3. 同步邮件元数据和必要正文，提取、规范化并去重链接，记录标题、类型、长度、预计投入和访问限制。
4. 结合当前请求、时间窗口、历史反馈和可访问性，只推荐一项有实质内容的链接，并报告索引变化与选择理由。
5. 根据后续请求阅读、总结、翻译、反馈、暂时跳过或重试；一次只处理当前项。
6. 归档或永久排除时，先重新确认唯一来源邮件与最新邮件 ID，再请求或核对用户授权。
   - 完成：移动到 `Archive`。
   - 永久排除：移动到 `Deleted Items`，不永久删除。
7. Outlook 移动成功后才更新本地状态，并报告准确来源、目标文件夹和索引结果。

## 停止条件

- 项目索引无法初始化或读取时立即停止。
- 存在多个同名文件夹、邮件身份不唯一或最新邮件 ID 无法确认时停止。
- 页面不可访问时不推荐、不自动删除；先说明原因并询问下一步。
- 用户未确认归档或排除时不得移动邮件；Outlook 移动失败时不得更新本地最终状态。

## 最终交付

推荐时交付名称、类型、链接、预计投入、来源与理由；处理后交付内容结果、索引统计，以及任何经过确认的邮件移动结果。
