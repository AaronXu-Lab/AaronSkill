# AW Meta Skill 工作流

本文档是执行 AW Meta Skill 时优先读取的文本工作流，也是 `workflow.svg` 的语义事实源。SVG 仅是与本文档同步的可视化投影；若两者不一致，先依据 `SKILL.md` 修订本文档，再同步 SVG。

## 输入与产物

- 输入：创建或更新目标 SKILL 的请求、目标路径、用途与范围。
- 产物：符合 `skill-creator` 基础规范与 AW 附加契约的目标 SKILL，其中包含 metadata、`docs/workflow.md` 和 `docs/workflow.svg`，并通过基础校验与 AW 附加校验。

## 执行步骤

1. 接收请求并确认目标 SKILL 的路径、用途和修改范围。
2. 定位并完整读取当前环境中的 `skill-creator/SKILL.md`。
   - 若不可用：停止，报告基础 Skill 缺失，不凭记忆重建规则。
   - 若可用：继续执行。
3. 判断目标 SKILL 是否存在。
   - 新建：优先运行 `skill-creator` 的标准初始化器，建立 `SKILL.md` 与必要资源。
   - 更新：检查现有 `SKILL.md`、`docs/workflow.md`、`docs/workflow.svg`、脚本、引用资料和调用关系；保留范围外的字段、资源与策略。
4. 按用户真实用途与基础规范编写或修订目标 SKILL，保持描述可发现且具区分度，只增加确有必要的资源。
5. 维护 `metadata.version`、`metadata.author` 和 `metadata.creation_context`。现有 SKILL 默认提升 MINOR（`+0.1.0`）；明确的小改动提升 PATCH（`+0.0.1`）；只有用户明确要求时才提升 MAJOR，否则遇到不兼容改动应停止确认。
6. 先创建或同步目标 SKILL 的 `docs/workflow.md`。它面向 AI 执行，是完整、精确的事实源：可以保留必要的工程术语、命令、状态、关键判断、停止条件、异常路径和最终产物，只要结构清楚且不复制整份 `SKILL.md`。
   - 多分支、回路、并行关系或跨阶段依赖会因纯文字难以整体追踪时，增加 Mermaid 图；按语义选择 `flowchart`、`sequenceDiagram` 或 `stateDiagram-v2`，简单线性流程不强制使用。
   - Mermaid 负责精确展示结构，正文负责定义可检索的条件和操作要求。不能只画图而省略关键规则，也不要为了与 SVG 一一对应而删减 Mermaid 的工程细节。
7. 再从 `workflow.md` 提炼 `docs/workflow.svg`。它面向人类快速理解，是语义一致的概览而非逐节点转录。
   - 先回答「这项工作为什么做、主要经过什么阶段、最终得到什么」，保留认知上必要的分支；节点数量由真实流程决定，不设固定目标。
   - 合并脚本命令、文件名、状态码、重试回路和实现细节；只有会改变读者对整体流程理解的门槛、停止点或分支才进入图中。
   - 不得把不同实现路径、授权门槛或交付状态压成误导性的笔直主线；这些结构必须在 SVG 中可见，只有细粒度状态与完整异常回路留在 Mermaid 和正文中。
   - 节点使用自然语言动作短语，说明最多一行；目标是在常规尺寸下一屏扫完，而不是把 Markdown 画成状态机或文档截图。
   - SVG 与 Markdown 要保持阶段顺序、核心决策和交付结果一致，但不要求节点数量、术语粒度或分支逐项对应。省略细节不算不一致，改变语义才算。
   - 默认使用 1200 宽浅灰画布、系统字体和自上而下主流程；按统一色义表达白色输入、蓝色执行、黄色判断、红色停止和绿色交付。
   - 连线从节点边界出发并在目标边界结束，不穿过节点或文字；优先通过减少分支、调整布局或扩展留白来保持清楚。
   - 已有 SVG 只有在用户要求重画、流程变化或该图进入修改范围时才迁移，不批量改动范围外文件。
8. 运行 `skill-creator` 基础校验器和 AW 附加校验器；有脚本时运行最小相关测试。
9. 人工复核内容质量、版本合理性，以及 `SKILL.md`、`workflow.md`、`workflow.svg` 三者的语义一致性；确认 Markdown 正文与 Mermaid 足以让 AI 精确执行，SVG 能让首次接触的人快速复述主流程及关键分支。渲染 SVG 做视觉检查，确认信息密度适中、文字清楚且连线无重叠。
10. 报告目标路径、旧版本到新版本的明确变化、metadata 取值、两种工作流文档状态和全部校验结果；任何版本变化都必须主动通知用户。

## 停止条件

- `skill-creator` 不可用时立即停止。
- 缺少会实质改变目标用途、授权范围或 author 身份的必要信息，且无法从可靠上下文推断时，停止并向用户确认。
- 改动具有不兼容性但用户没有明确要求升级 MAJOR 时，停止并确认版本方向。
- 基础校验、AW 附加校验或必要测试失败时，不得宣称交付完成；先修复，无法修复则报告具体阻塞。
