# 扫描器用法

用于文件、目录或批量源码审查；单句、截图或纯语义判断无需读取本文。规则定义与例外在 [规则集](rules.md)，扫描器不会修改文件。

## 调用与选择

在目标仓库根目录执行，脚本使用本 Skill 的绝对路径，范围使用实际文件或目录：

```bash
python3 <Skill绝对路径>/scripts/check_copy.py <范围路径> --json
```

只有需要查明完整 ID 或检查命名禁令时才使用以下辅助命令；已有本次有效结果可复用：

```bash
python3 <Skill绝对路径>/scripts/check_copy.py --list-rules
python3 <Skill绝对路径>/scripts/check_copy.py <范围路径> --list-bans
```

| 选择 | 参数（可重复的项目可多次传入） |
| --- | --- |
| 只查某几条规则 | `--rule <完整ID>`，可重复 |
| 跳过某条规则 | `--skip-rule <完整ID>`，可重复 |
| 补充命名禁令 | `--ban <TERM>`，可重复 |
| 排除误提取的禁用词 | `--skip-ban <TERM>`，可重复 |
| 指定禁令来源 | `--agents-md <文件>` |
| 关闭自动提取 | `--no-agents-md`；显式 `--ban` 仍生效，不免除遵循已知项目约束的责任 |

用户选择和项目例外要落实到参数；覆盖了通用默认值的项目约定不能仍按默认值报 error。无法用参数表达的项目规则单独语义复核，并说明覆盖的默认项。未知规则 ID 会报错，选择在规则执行前生效。

退出码：`0` 没有 error（仍可能有 warn），`1` 发现 error，`2` 参数错误、路径缺失或读取失败。检查退出码和实际输出；失败不得当作零命中通过。

## 提取范围与局限

19 条机械规则覆盖 A1–A3、B1–B3、C1–C6、D1、D5、E1、F1、F3、G8、H2，另有项目命名禁令。机械覆盖只代表这些条目的可判定部分，例如 H2 只查单位间距、C6 不判断 description 的完整语义。

提取含汉字的字符串值与标记文本，另检查 `value` 或空值回退中的 `N/A`、`--` 等字段占位符。JSON 的 `title` / `placeholder` 等角色参与检查。排除属性 key、注释与日志，遮蔽插值、URL、文件名和免空格专有名词；名称、术语与豁免表由规则集链接，脚本会自动读取所需表。

只扫描支持的源码后缀；语言目录按 i18n 标记之后的 locale 过滤非简体中文。未标注 locale 的混合语言文件仍需检查语境。提取是启发式而非完整 AST：复杂表达式、嵌套模板、转义和正则可能需要源码复核，不能把未提取内容记为已验证。

## 项目命名禁令

脚本从目标路径向上查找 `AGENTS.md` / `CLAUDE.md` / `AGENTS.design.md`，提取拉丁标识符或引号包裹的禁用词。拉丁词匹配及 `--skip-ban` 大小写不敏感。

有“工程代码、标识符、变量、文件名”等信号且没有“文案、界面”信号的禁令只约束代码命名，默认不进入文案扫描；`--list-bans` 会单独列出。用户明确要求检查其展示文案时可用 `--ban` 纳入，不因此扫描或改写代码标识符。

提取会跳过 `useContext` 等代码约束和“禁止使用炒作话术”等范畴描述，也可能漏掉自然语言禁令。结合本次适用项目文档补充，不为提取所有可能禁令通读无关资料。只有完整预检或影响结论时才展开来源与排除清单。
