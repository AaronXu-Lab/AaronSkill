## 权重原则

先按时间给基础权重，再按作者性和体裁乘修正系数。最新文章优先，但“最新”不能覆盖“并非作者声音”。

### 时间基础权重

| 时间 | 权重 |
| --- | ---: |
| 2026 | 1.00 |
| 2025 | 0.85 |
| 2024 | 0.75 |
| 2022 - 2023 | 0.55 |
| 2019 - 2021 | 0.35 |
| 2018 及以前 | 0.20 |

### 内容修正系数

| 类型 | 系数 |
| --- | ---: |
| 原创实践复盘、产品分析、观点文章 | 1.00 |
| 原创个人随笔、文化评论 | 0.90 |
| 原创教程、技术笔记 | 0.80 |
| 资讯整理、发布解读 | 0.60 |
| 清单、轻度推广、作品展示 | 0.45 |
| 转载、翻译、隐私政策 | 0 |
| 明确标记为 GPT / AI 生成的段落 | 0，作为负样本 |

按段落覆盖文章级权重。同一篇文章可以同时包含正样本和负样本。

## 旧文的作用

旧文只用来确认长期稳定特征，不让其覆盖当前语气：

- 第一人称承担经历来源。
- 喜欢保存具体数字、设备、操作和失败细节。
- 专业解释中自然出现口语转折。
- 愿意直接说没想明白、没做完或“不写了”。

不要恢复旧文的长段落、标点问题和未经整理的流水账。

## 刷新步骤

当有新文章时：

1. 按段落识别原创、引用、翻译和 AI 生成内容。
2. 计算时间权重与内容修正系数。
3. 先找新文章是否改变了深层写作心态，再看词汇变化。
4. 只有跨至少三篇高权重原创文章重复出现，才把新特征视为趋势。
5. 把只在一篇出现的高辨识度说法当作局部表达，不写成规则。
6. 使用新文章更新 `voice-model.md` 和对应体裁，不建立口头禅词库。
7. 保留至少一篇最新高权重文章作为留出样本，不参与规则提炼，用于验证泛化。
